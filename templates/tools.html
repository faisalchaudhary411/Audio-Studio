Choosing a tool

Which VoxCraft tool should you use?

Pick the smallest tool that matches the job. Keeping the workflow focused can make processing faster and helps preserve the original recording when you only need a simple change.

Need text from speech?

Use Transcribe to turn supported audio recordings into text. Clear speech and limited background noise generally produce better transcripts.

→

Need a different file format?

Use Convert when you need MP3, WAV, OGG, M4A or FLAC output. Keep the original file if you may need to make a different conversion later.

→

Need to edit a recording?

Use Merge, Cutter or Denoise for common editing tasks without opening a full desktop editor.

Need a voice effect?

Voice Changer provides pitch, robot, echo, chipmunk and deep-voice effects for clips where a deliberate character or processing effect is wanted.

→

Need audio from a video?

Video to Audio extracts an audio track from supported video formats so you can continue editing or converting it separately.

→

Need a quick music bed?

Music Generator is available to Pro+ users for generating tracks from a description. Check the current licensing information before using generated music commercially.

Before processing an important recording

Keep an untouched copy of the original. Choose a sensible output format, avoid repeated lossy conversions, and listen to the result before deleting your source. Processing cannot reliably restore information that was never captured or was already lost through heavy compression.

Audio workflow tips

Start with the cleanest source you can.

Good microphone placement, moderate recording levels and a quiet room usually produce better results than aggressive processing after the fact. For speech, keep the speaker reasonably close to the microphone and avoid clipping the input.

For transcription

Use a recording with clear speech and as little competing sound as possible. If several people speak at once, review the generated transcript rather than assuming every word will be separated perfectly.

For noise removal

Steady room noise is a better candidate for denoising than sudden sounds. Start with moderate processing: excessive noise reduction can make speech sound metallic or unnatural.

For format conversion

Choose WAV or FLAC when preserving quality matters and MP3 when a smaller, broadly compatible file is more useful. Converting an already compressed MP3 to another lossy format does not restore the lost detail.

Frequently asked questions
Are my files permanently stored?

Check the VoxCraft Privacy page for the current handling and retention information for uploaded files and generated results.

What happens if a file is too large?

Each tool shows its current file limit before processing. A file above that limit should be reduced or split before uploading.

Should I keep my original file?

Yes. Keeping an untouched original is the safest way to retry with different settings or formats.
