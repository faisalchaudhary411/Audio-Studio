Transcribe

Converts speech in an audio file to text. Supports WAV, MP3, M4A, OGG, FLAC — up to 10MB. Long files are processed in chunks, so it works for anything from a voice memo to a full interview.

Convert

Changes an audio file's format and bitrate. Supports MP3, WAV, OGG, M4A, FLAC — up to 10MB.

Merge — combine 2 or more clips, in order

Stitches multiple clips into one file with a configurable silence gap between them. Up to 10MB per file.

Tap "Add files" as many times as you need — each pick adds to the list below rather than replacing it. Max 10MB per file.

Cutter

Trim a clip to a start/end range, or split it into two files at a chosen point. Up to 10MB.

Denoise

Reduces background hiss/hum using spectral noise reduction. Works best on speech with fairly steady background noise (fans, room tone) — won't remove sudden noises like claps or barks. Up to 10MB. Output is mono.

Voice Changer

Applies an effect to a voice clip — Pitch Shift preserves the original speaking speed while changing pitch; Chipmunk/Deep Voice intentionally change both pitch and speed for a character-voice effect. Up to 10MB.

Video to Audio

Extracts the audio track from a video file. Supports MP4, AVI, MOV, MKV, WEBM — up to 50MB (larger than the other tools, since video files are naturally bigger). Files over the limit, or corrupted/incomplete uploads, will fail with an error rather than a silent hang.

Choosing a tool

Which VoxCraft tool should you use?

Need text from speech?

Use Transcribe to turn supported audio recordings into text.

→

Need a different file format?

Use Convert when you need MP3, WAV, OGG, M4A or FLAC output.

→

Need to edit a recording?

Use Merge, Cutter or Denoise for common editing tasks.

Good to know

Every tool shows its supported formats and relevant file limits before processing. Results can depend on the source recording: for example, noise reduction works best on steady background noise and cannot reliably remove every sudden sound or heavily distorted recording.

Audio workflow tips

Start with the cleanest source you can.

Good microphone placement, moderate recording levels and a quiet room usually produce better results than aggressive processing after the fact. Keep an original copy of important recordings before converting or editing them.
