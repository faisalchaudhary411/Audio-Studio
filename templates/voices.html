Tips

Get the best results

Native script when possible

For Urdu and Hindi, write in Nastaliq or Devanagari instead of pure Roman letters — pronunciation is noticeably clearer.

Match the primary language

Pick a voice whose language matches the dominant language of your script. Mixed English terms still work fine inside an Urdu or Hindi sentence.

Preview before long scripts

Use the short preview line in Studio to check pacing and tone, then generate the full script.

Only a few samples on this page

We host a small set of preview clips here. Every voice still works in Studio — generate a few seconds free to hear it.
