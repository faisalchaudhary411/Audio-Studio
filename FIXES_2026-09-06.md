# VoxCraft fixes — 2026-09-06

## 1. Broken buttons / cheap animation & style

**Cause:** `.btn` lacked `white-space: nowrap` and `flex-shrink: 0`. On the clone page the long status string next to **Clone & generate** squeezed the button so the label wrapped letter-by-letter (what you saw in the screenshot). Loading spinner and progress bar were also weak.

**Fixed in** `static/css/style.css`:
- Buttons never wrap; min-height / flex-shrink for stable layout
- `.render-bar` stacks on small screens instead of crushing the button
- Smoother `gen-progress` shimmer animation
- Cleaner loading spinner (`is-loading`)

Hard-refresh (Ctrl+Shift+R) after deploy so CSS isn’t cached.

---

## 2. Voice clone + music not sharing files with other tools

**Cause:** Chatterbox / F5-TTS (clone) and Ace-Step (music) either didn’t write `sessionStorage`, or wrote it without a consistent result panel; destination tools sometimes didn’t run the “Use this file” banner. Large WAVs could also blow sessionStorage quota silently.

**Fixed:**
- Shared helpers in `static/js/main.js`: `voxSaveTransfer`, `voxAudioPlayerHtml`, `voxOfferIncomingTransfer` (quota-aware, ~4MB cap)
- `clone_music.js` and `music.js` now use that shared result panel with **Send to** links
- `tools.js` and `studio.js` delegate to the same helpers
- Incoming transfer banner runs on any page with a file input (including clone)

Flow: generate → Download / Send to Trim|Denoise|… → on the next tool, click **Use this file**.

---

## 3. Whisper wrong transcription (Google was better)

**Cause:** Worker used default faster-whisper settings that hallucinate / loop on Urdu & Hindi; language codes weren’t normalized; no auto-detect option.

**Fixed in** `modal_workers/whisper/app.py` + `audio_tools.py`:
- `temperature=0`, `condition_on_previous_text=False` (cuts repetition loops)
- Better beam / VAD padding for quiet speech
- Script-aware `initial_prompt` for `ur` / `hi`
- Hallucination de-dupe for stuck short-token loops
- Language normalized to ISO-639-1; `auto` supported
- Transcribe UI: **Auto-detect language** option

**Deploy note:** redeploy the Modal Whisper worker after pulling:

```bash
modal deploy modal_workers/whisper/app.py
```

Then restart the web app so it picks up `audio_tools.py`.
